Where do I get the GitHub token?
  1. Go to GitHub → Fine-grained tokens.
  2. Name it menu-admin and set expiry to No expiration (or a long date).
  3. Under Repository access choose Only select repositories → pick your menu repository.
  4. Under Permissions → Repository permissions, set Contents to Read and write.
  5. Generate token, copy it, and paste it above.
Why the password has to be a long one

Your locked token is stored as auth.json in the repository, which is a public file — that is the only way a website with no server can remember anything. It is encrypted, and the encryption is slow on purpose, but someone who downloads it could sit and guess passwords against it on their own machine. A long password (four or five unrelated words is ideal) makes that hopeless. A short one does not.
